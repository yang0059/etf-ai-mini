MINI LLM PROJECT

ETF 入門小助手

一個 Python 小程式，呼叫本機 AI 模型，讓初學者用三點快速認識 ETF。

Python + uvOllama串流輸出 StreamingGitHub Pages

01 / 做了什麼？

程式向本地 Ollama 的 /api/generate 送出 ETF 入門問題，設定 stream: true，收到片段就即時印到終端機，最後儲存至 docs/result.txt。

主題：ETF 基本概念、優點與投資風險。此作品是學習示範，不提供個別投資建議。

02 / 怎麼執行？

先安裝 uv 與 Ollama，確保 Ollama 正在執行，然後於專案資料夾輸入：

ollama pull qwen2.5:0.5b
uv run main.py

無需 API Key，模型約 398 MB。若尚未安裝 uv，請見 README。

04 / AI 使用說明

本作品使用 AI 協助規劃與撰寫範例程式、說明文件和作品頁。實際內容生成由本機 Ollama 的 qwen2.5:0.5b 執行，透過串流回傳。模型可能出錯，ETF 說明應自行查證。
